## 6. Required Release Checks

Before deployment:

1. Commit and push the reviewed changes.
2. Create a GitHub Pull Request into main.
3. Confirm all GitHub Actions checks pass.
4. Review Firebase Authentication providers and authorized domains.
5. Keep a copy of the currently published Firestore rules.
6. Confirm the correct Firebase production project.
7. Deploy Hosting and Firestore rules only after the release review.

Deployment command:

firebase deploy --only hosting,firestore:rules --project auto-spot-hub

## 7. Production Limitations

This project is currently a portfolio/demo marketplace.

- Checkout does not process real payments.
- Order prices and tax calculations are generated by the browser.
- Reviews currently use browser localStorage.
- Login and activity audit writes require trusted backend implementation.
- Real commerce requires trusted server-side pricing, payment verification and order processing.
- Firebase App Check, monitoring and abuse controls should be configured before accepting real customers.

A successful Firebase deployment publishes the portfolio website and its Firestore rules. It does not make the demo checkout a production payment system.
